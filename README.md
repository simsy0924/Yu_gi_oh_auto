# Yu-Gi-Oh! Duel Sandbox

모바일 가로 화면 기준으로 다시 시작한 듀얼 샌드박스 프로젝트입니다.

현재 버전은 **기본 UI 프로토타입만** 들어 있습니다.

- P1 / P2 필드 동시 표시
- 상대 측 카드 방향 180도 유지
- LP / 패 / 덱 / 엑스트라 덱 / 묘지 / 제외 영역
- 엑스트라 몬스터 존
- 우선권 표시 및 전환
- 수동 시점 전환
- 턴 / 페이즈 전환
- 모바일 세로 화면 회전 안내
- Undo / Redo / Card / State / More 버튼 자리

카드 데이터, 덱 로딩, 드래그 앤 드롭, 룰 처리, ygopro-core 연동은 아직 구현하지 않았습니다.
