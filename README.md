# Yu-Gi-Oh! Ghost Duel

모바일 가로 화면에서 **고스트와 혼자 듀얼하는 기능만** 만드는 프로젝트입니다.

## 범위

이 프로젝트는 범용 샌드박스나 양쪽 수동 조작기를 목표로 하지 않습니다.

흐름은 단순하게 유지합니다.

1. 고스트 패키지 선택
2. 내 덱 선택
3. 듀얼 시작
4. 상대측 행동은 고스트가 담당
5. 사용자는 자기 카드와 선택지만 조작

## 현재 상태

현재는 Ghost Duel 전용 UI 프로토타입만 들어 있습니다.

- 고스트 선택 화면
- 내 덱 선택 화면
- 모바일 가로 듀얼 필드
- 상대 카드 방향 180도 유지
- Ghost / You LP와 기본 존
- 고스트 상태 표시 자리

아직 실제 카드 데이터, 덱 파일 로딩, 카드 조작, 룰 엔진, ygopro-core 연결, 고스트 행동 로직은 구현하지 않았습니다.
